
# AnyScan Overview

AnyScan is a secure, cloud-based scan-to-cloud solution that enables users to capture documents and route them directly to configured cloud or on-premises destinations across an organization.

It integrates with supported providers and workflow configurations to streamline document management across multiple departments and locations.

AnyScan supports document routing in distributed environments, including:

* Head offices and branch offices
* Remote and hybrid work environments
* Shared departmental storage locations
* Centralized document management systems
* Cloud-based collaboration platforms

This allows scanned documents to be delivered to the appropriate destination regardless of the user's physical location.

## Key Functions

AnyScan provides the following core functions:

* **Scan-to-Cloud:** Sends scanned documents to configured destinations through linked cloud providers.
* **Workflow Routing:** Routes documents based on configured rules and workflows.
* **User Authentication:** Ensures that only authorized users can scan and upload documents.
* **Provider Integration:** Connects with supported third-party storage platforms for document sharing and routing.
* **Secure Transmission:** Uses encrypted communication to help protect data during transmission.
