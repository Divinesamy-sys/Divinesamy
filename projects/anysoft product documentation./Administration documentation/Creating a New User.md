
# Creating a New User

This article explains how administrators can create a new user in the AnySoft Portal.

Users must be created and configured before they can access AnySoft services such as AnyScan, AnyPrint, or AnyDrive.

## Requirements

You must have administrator permissions to create or manage user accounts.

Before creating the account, ensure that you have the user's required information, including a valid email address.

The email address may be used for account activation and sign-in.

## Steps

### Step 1: Sign in to the AnySoft Portal

Sign in to the AnySoft Portal using an account with the required administrator permissions.

### Step 2: Open Users

From the Portal dashboard, navigate to **Users**.

### Step 3: Add a User

Click **Add User**.

### Step 4: Enter User Information

Enter the required user details, such as:

* Full name
* Email address
* Temporary password, if required
* Role
* Tenant, if applicable

### Step 5: Assign Licenses

Assign the appropriate product licenses to the user.

The available licenses depend on the products and subscription configured for the organization.

### Step 6: Save the User

Review the information and click **Save** to create the account.

## Verification

After saving the account, verify that:

* The user appears in the **Users** section.
* The correct role is assigned.
* Required licenses have been assigned.
* The user's account status is correct.
* The user can complete the required activation or sign-in process.
