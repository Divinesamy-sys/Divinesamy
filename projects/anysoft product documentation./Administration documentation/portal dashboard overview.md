
# Portal Dashboard Overview

The AnySoft Portal dashboard provides administrators with a central view for monitoring system activity, managing users and resources, and accessing administrative configuration settings.

After signing in to the Admin Portal, administrators are directed to the dashboard.

The exact information displayed may vary depending on the administrator's permissions, enabled products, and tenant configuration.

## Dashboard Purpose

The dashboard provides an overview of the tenant and provides access to common administrative functions.

Typical administrative tasks include:

* Monitoring user activity
* Viewing license status and usage
* Managing users
* Accessing configuration settings
* Managing providers and integrations
* Reviewing authentication settings
* Identifying issues that may require attention

## Main Dashboard Sections

### Dashboard

The dashboard provides a summary of important tenant information, which may include:

* Total number of users
* Active license seats
* System status indicators
* Tenant administrator information

### Users

The **Users** section provides information about registered users.

Depending on the configuration, administrators may be able to view:

* User name
* Role
* Email address
* Last login date
* Account creation or join date
* License type
* Account status

A search function can be used to locate specific users, which is particularly useful in larger organizations.

### Licenses

The **Licenses** section provides information about product licensing and seat allocation.

Administrators can use this area to review:

* Available seats
* Assigned seats
* User license status
* Product-specific licensing information

Products may include:

* AnyPrint
* AnyScan
* AnyDrive

### Billing

The **Billing** section provides access to billing and subscription information for enabled products.

Available information may vary according to the tenant's subscription and billing configuration.

### Settings

The **Settings** section provides access to administrative configuration options.

Depending on the environment, settings may include authentication and OAuth configuration.

For example, OAuth configuration can allow supported external identity providers to be used for authentication.

## Permissions and Visibility

Dashboard content is role-based.

* Administrators typically have access to broader system information and configuration options.
* Users with limited administrative roles may see only the sections relevant to their permissions.
* Some panels may not appear if the corresponding feature is not enabled.
