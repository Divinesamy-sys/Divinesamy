
# How to Create a GitHub Repository

## Overview

A GitHub repository is a location where you can store and manage a project.

Repositories can contain source code, documentation, configuration files, images, and other project resources.

This guide explains how to create a new repository through the GitHub website.

## Prerequisites

Before you begin, make sure you have:

* A GitHub account
* Access to a web browser
* A project or documentation set you want to store

## Steps

### Step 1: Sign in to GitHub

Sign in to your GitHub account.

From the GitHub interface, select the option to create a new repository.

### Step 2: Enter the Repository Name

Enter a descriptive name for your repository.

For example:

```text
technical-writing-portfolio
```

Use a name that clearly communicates the purpose of the project.

### Step 3: Add a Description

Add a short description explaining what the repository contains.

For example:

```text
A portfolio of software documentation, technical guides, and developer-focused educational content.
```

### Step 4: Choose Repository Visibility

Select whether the repository should be:

* Public
* Private

For a portfolio, a public repository is generally appropriate when the content is safe to share publicly.

Do not publish confidential company, client, customer, or proprietary information.

### Step 5: Initialize the Repository

You can optionally add files such as:

* README
* `.gitignore`
* License

For a documentation portfolio, adding a README is useful because it gives visitors an introduction to the project.

### Step 6: Create the Repository

Review the repository settings and select **Create repository**.

GitHub creates the repository and opens its main page.

## Expected Result

You should now have a GitHub repository containing your selected initial files.

For example:

```text
technical-writing-portfolio/
└── README.md
```

You can then add folders, documentation files, images, and other portfolio projects.

## Next Steps

After creating the repository, you can:

1. Add your portfolio README.
2. Create a `projects` directory.
3. Add individual documentation projects.
4. Organize articles into folders.
5. Add screenshots and other approved assets.
6. Update the repository as you create new work.

## Troubleshooting

### I cannot create a repository

Make sure you are signed in to the correct GitHub account and have permission to create repositories.

### My repository is private

Check the repository's visibility settings if you intend to use it as a public portfolio.

### I cannot find my repository

Open your GitHub profile and check the **Repositories** section.

## Best Practices

Use descriptive repository names and organize files logically.

For a technical-writing portfolio, consider separating projects into folders such as:

```text
projects/
├── software-documentation/
├── crypto-web3/
├── developer-documentation/
└── troubleshooting/
```

Keep the README focused on what visitors need to understand about the project.
